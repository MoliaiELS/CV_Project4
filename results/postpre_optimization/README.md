# 汇报后补充实验

## Part 2 原始基线诊断

在课程服务器上以 CPU 核验三个场景的原始 7,000 步固定相机结果。逐项核对了六个检查点哈希、初始化与训练收据、留出图像身份和已归档的 alpha 支持度。全视角与稀疏条件的位姿诊断分别在同一组稀疏训练相机上拟合 Sim(3)。相对位姿使用原始序列中相邻的共同训练帧。平移误差使用各场景的参考轨迹单位，旋转误差使用度。 [诊断收据](part2_pose_baseline.json) · [复核脚本](../../scripts/part2_pose_diagnostics.py) · [原 Part 2 结果](../../docs/part2_results.md)

| 场景 | 注册数（全 / 稀疏） | 共同训练帧 | 留出帧 | ATE RMSE（全 → 稀疏） | 平均旋转误差（全 → 稀疏） | PSNR 变化（稀疏 − 全） |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Waymo-405841 | 174 / 20 | 20 | 25 | 0.95649 → 0.72937 | 1.053° → 2.214° | −0.963 dB |
| Dl3dv-2 | 267 / 11 | 11 | 39 | 0.03790 → 0.02903 | 0.573° → 0.473° | −3.130 dB |
| Re10k-1 | 244 / 10 | 10 | 35 | 0.02902 → 0.02643 | 3.478° → 3.853° | −0.130 dB |

全部条件注册了各自尝试的训练帧。三个场景的稀疏条件在共同帧上的 ATE 更低，同时留出 PSNR 均下降。Waymo 与 Re10k 的平均绝对旋转误差增大。Re10k 的两个条件中，估计 `fx` 与 `fy` 的平均绝对相对误差均约为 19–21%。这些量刻画不同方面的误差，当前对照提供的是关联证据。稀疏条件下，累计 alpha ≥ 0.9 的留出像素比例分别下降 2.16、3.68 和 3.58 个百分点。该比例描述投影支持度，仅作为覆盖代理。 [逐帧 alpha](../part2_supplement_v1/coverage_per_frame.json) · [Part 2 相机审计](../../docs/part2_camera_preprocessing_audit.md)

### 训练图像的保留观测重投影

两组共享同一份训练图像 SIFT 对应。用每条三视角及以上轨迹的首尾像素和各自估计相机三角化，再计算中间训练图像像素的重投影误差。三角化与投影全过程使用估计相机。对应构建和图像几何验证使用同一批训练图，中间像素的保留范围是三角化阶段。

| 场景 | 两组均有效的观测 / 尝试数 | 重投影中位误差（全 → 稀疏） |
| --- | ---: | ---: |
| Waymo-405841 | 186 / 3,883 | 8.068 → 4.680 px |
| Dl3dv-2 | 91 / 156 | 0.976 → 1.020 px |
| Re10k-1 | 591 / 722 | 0.816 → 0.780 px |

数字限于两组均通过正深度、视差及锚点误差筛选的同一批观测。Waymo 的共同有效比例为 4.8%，因此它的中位数只代表这个有效子集。每组各自有效的样本数、共同子集的 P90 与逐帧位姿误差见收据。

课程项目说明 §6.2 要求在留出集报告 PSNR、SSIM、LPIPS，另报告 Part 2 的 ATE RMSE 和运行时间。该节未设 30 dB 门槛。比较外部 PSNR 需要核对场景、输入与留出帧、分辨率、相机及颜色协议。 [仓库的冻结评估规则](../../docs/validation.md)
