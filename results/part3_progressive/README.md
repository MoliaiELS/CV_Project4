# Part 3 补充实验

使用课程服务器、原稀疏训练划分和原留出测试图，统一报告未经后处理的 3DGS 渲染。完整闭环每轮训练 3,000 步、选取 8 个目标视角，种子为 42。 [运行说明](../../docs/part3.md#补充实验) · [原 Part 3 对照](../part3/comparison.csv)

| 场景与条件 | 第二轮 PSNR ↑ | SSIM ↑ | LPIPS ↓ | 相对同起点仅真实图像续训的 PSNR |
| --- | ---: | ---: | ---: | ---: |
| DL3DV 渐进双参考 | 15.5029 | 0.456895 | 0.256381 | +0.0309 dB |
| Re10k 渐进双参考 | 11.2490 | 0.274544 | 0.405020 | +0.0056 dB |
| Re10k 渐进双参考，伪观测权重 1.0 | 11.2639 | 0.2753 | 0.4034 | +0.0205 dB |
| Re10k 相机校准后渐进双参考 | 10.8458 | 0.261455 | 0.447130 | +0.0101 dB |

- [渐进双参考和原始渲染回放](progressive.csv) 从已归档的两个稀疏 M0 开始。第二轮比原始渲染回放分别高 0.0081 和 0.0067 dB。两个新分支共核对了 370 张渲染，使用原来的 74 个测试视角。每个场景中，两分支两轮都选到了相同的目标相机。
- [Re10k 权重对照](weight_1.csv) 用相同的原始 M0、生成流程和训练预算，将伪观测损失权重从 0.2 提到 1.0。第二轮比 0.2 高约 0.0149 dB。
- [相机校准诊断](refinement.json) 中留出的 153 个训练特征观测重投影误差中位数从 0.795 降到 0.424 像素。[重训及两轮对照](calibrated.csv) 中校准后的稀疏 M0 从 11.2342 降到 10.8044 dB，第二轮回灌后为 10.8458 dB。

这些单种子实验提供了匹配对照，场景间的可重复性仍需更多数据检验。
