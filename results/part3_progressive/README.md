# 历史闭环基线

两项基线从原稀疏 VGGT + 3DGS 模型起步，每轮使用八个目标视角、3,000 步和固定种子 42。指标来自原始 3DGS 留出渲染。

| 场景 | 第二轮方法 | PSNR | SSIM | LPIPS |
| --- | --- | ---: | ---: | ---: |
| [DL3DV](warp_weight_04.csv) | 真实纹理投影与双参考 Difix 补洞，伪观测权重 0.4 | 15.6056 | 0.4651 | 0.2512 |
| [Re10k](weight_1.csv) | 渐进双参考加权，伪观测权重 1.0 | 11.2639 | 0.2753 | 0.4034 |

这两项是[改进起点实验](../part3_mse30/README.md)的 MSE 比较基准。复跑时按同一留出集生成逐帧指标。 [历史基线复现](../../docs/part3.md#历史渐进闭环基线)
