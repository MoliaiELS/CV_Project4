# Part 3 补充实验

- [渐进双参考和原始渲染回放](progressive.csv) 从已归档的两个稀疏 M0 开始。第二轮比原始渲染回放分别高 0.0081 和 0.0067 dB。两个新分支共核对了 370 张渲染，使用原来的 74 个测试视角。每个场景中，两分支两轮都选到了相同的目标相机。
- [DL3DV 真实纹理投影对照](warp_weight_02.csv) 沿用同一个 M0 和 39 张留出图像。两轮中约 71%–72% 的像素获得可靠的真实纹理投影，约 8% 由扩散补洞追加监督。联合分支比原 Part 3 最终结果高 0.0778 dB，比相同权重的纯投影分支高 0.0128 dB。两分支每轮选到相同目标相机。
- [DL3DV 权重 0.4 对照](warp_weight_04.csv) 的联合分支比原 Part 3 最终结果高 0.1047 dB，比原 M0 高 0.1270 dB。39 个视角中 34 个 PSNR 改善，中位增益为 0.0633 dB。相对同权重的纯投影分支，联合闭环增加 0.0171 dB，包含第二轮重新规划的影响。 [逐帧核验摘要](warp_verification.json) · [中位增益和最差案例](heldout_warp.png) · [示例帧数据](heldout_warp.json)
- [Re10k 权重对照](weight_1.csv) 用相同的原始 M0、生成流程和训练预算，将伪观测损失权重从 0.2 提到 1.0。第二轮比 0.2 高约 0.0149 dB。
- [相机校准诊断](refinement.json) 中留出的 153 个训练特征观测重投影误差中位数从 0.795 降到 0.424 像素。[重训及两轮对照](calibrated.csv) 中校准后的稀疏 M0 从 11.2342 降到 10.8044 dB，第二轮回灌后为 10.8458 dB。

这些单种子实验提供了匹配对照，场景间的可重复性仍需更多数据检验。
